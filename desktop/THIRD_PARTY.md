# Third-party components in Modot Preview

The terms for Modot's own source are in [LICENSE](../LICENSE) and its [Chinese translation](../LICENSE.zh-CN.md). Earlier MIT grants remain in effect for the material they covered. The [historical MIT notice](../docs/licenses/previous-modot-mit.txt) is also included under `licenses` in the application archive. Each dependency retains its own license, copyright notices and upstream terms.

| Delivered component | Where to find the version, source and notices |
| --- | --- |
| Electron 45 and Chromium | The install directory contains `LICENSE.electron.txt` and `LICENSES.chromium.html`. [Electron](https://github.com/electron/electron) |
| CPython 3.13 on Windows x64 | The unpacked runtime includes `python/LICENSE.txt`, the standard library and its notices. [CPython](https://github.com/python/cpython) |
| Python distributions | The installer ships pywinpty, debugpy, Pillow, pypdf, openpyxl, et_xmlfile, defusedxml, PyYAML, tzdata, Dulwich and urllib3. Versions are [pinned](requirements-release.txt). Each distribution keeps its metadata and license files in `python/Lib/site-packages`. |
| Renderer and Node.js declarations | The [renderer lockfile](renderer-v2/package-lock.json) and [desktop lockfile](package-lock.json) name the dependencies. The app archive includes `licenses/renderer-components.json` and upstream license files under `licenses/renderer`. It uses Shiki with the GitHub Light and Dark themes. The TS/JS plugin ships the TypeScript declarations and MIT notices for `@types/node` and `undici-types` in `workroom-typescript-libs`. |
| Git for Windows | Setup downloads and verifies the original MinGit ZIP. The exact artifact is [pinned](installer/runtime-assets.json). The installed Git tree includes `git/LICENSE.txt` and component notices. [Git for Windows](https://github.com/git-for-windows/git/releases) |
| PyAV and video FFmpeg | The installer bundles a [SHA-256-pinned PyAV 19.0.2 wheel](installer/video-runtime.json) built against FFmpeg 9.0.2 under LGPL 2.1 or later, with dav1d software AV1 decoding. The wheel includes its license files. Additional runtime notices are under `licenses/video` in the application archive. Download the matching `Modot-<version>-Video-Sources-and-Notices.zip` alongside the installer for the exact source archives, configuration, build scripts and separate Electron FFmpeg materials. The shared libraries use their normal names and can be replaced by ABI-compatible builds under the applicable LGPL terms. [PyAV](https://pypi.org/project/av/) · [FFmpeg license information](https://ffmpeg.org/legal.html) |

The app archive contains the staging inventory in `release-manifest.json`. It records the bundled file hashes, the video wheel and its corresponding source archive, and the pin for the MinGit download. Release asset SHA-256 values are recorded separately with the download.
