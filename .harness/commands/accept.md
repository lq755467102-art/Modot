先跑一遍验收，再看结果：

    python bin/accept.py

要求：
1. 末行必须是 `===== N/N 通过 =====` 且 N 相等；不相等就是有红项，逐条读 `←` 后面的原因。
2. 带 `⊘` 的是"没验"，既不算通过也不算失败，别把它的算进 N。
3. 有红项先判断是"实现错了"还是"设计变了"：
   - 实现错了 ⇒ 改实现
   - 设计变了（有人明确要求换做法）⇒ 改断言，并在提交信息里写清为什么
4. 跑完再跑 `python bin/residue.py`，它查"同一个错法有没有在别处重现"。
