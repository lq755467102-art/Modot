## 初版审查记录

初版预览从开发主线 `4faa7886` 中选入产品源码，在独立历史中准备发布。下表记录该次对提供方请求、附件读取、工作记录和格式化，以及源码安装、打包、凭据隔离与 Windows 安装的审查。完整仓库和所有第三方代码还没有经过独立安全审计。

| 发现 | 对用户的影响 | 修正与验证入口 |
| --- | --- | --- |
| 同一画面由两次操作读取，压缩后只保留了其中一次 | 两次读取可能同时出现「图像已送入模型」回执 | 在最终请求里按图像和来源动作逐项确认。本机来源标记留在请求组装器。覆盖完全相同像素和只保留第二次的情形。[请求回执](../loop/image_evidence.py) · [回归用例](../tools/test_public_preview.py) |
| 表格读取期间撤销了附件访问权 | 在目录信息已经解析的窗口内，旧请求可能仍返回工作表名称 | 返回前再次核对授权范围和源文件摘要。中途撤权的请求收到 403。[读取实现](../loop/projects.py) · [回归用例](../tools/test_public_preview.py) |
| 记录了一条新接口观察，仍沿用上一条的来源与需求版本 | 模型可能把新结论记在错误的证据或轮次下 | 显式提交观察时保存本次依据，普通进度更新沿用原观察。模型自述与独立验收分别处理。[工作记录](../loop/working_context.py) · [跨轮用例](../tools/test_l0_contract_notes.py) |
| 源码环境缺少部分依赖，Windows 虚拟环境也缺独立沙箱目录 | 应用可启动，文档、视频或项目检查到实际执行时才失败 | 统一安装依赖；由正常 CPython 和已锁定的包准备独立运行时。源码安装和打包都能校验依赖。[开发指南](install.md) · [运行时准备](../desktop/scripts/prepare-python.cjs) |
| 打包后的安装进程无法加载 PowerShell 的文件哈希命令 | 上游文件下载成功，正常安装仍被中止 | 改由系统加密库流式计算 SHA-256。实际试装覆盖在线下载、有效缓存和错误缓存。错误文件被拒绝时已安装的应用保持原校验值。[安装脚本](../desktop/installer/prepare-components.ps1) |
| 格式化等待和失败提示有硬编码文案 | 切换英文时仍显示另一种语言或错误的操作提示 | 接回统一的界面语言与就绪状态，保留重试操作；前端通过 TypeScript 检查和生产构建。[格式化界面](../desktop/renderer-v2/src/DocumentFormatting.tsx) |

权限回归另核对了测试本身。一项检查原先在会话建立后修改「新会话默认权限」，随后假设旧会话已获得完全访问。公开版测试通过该会话自己的权限入口启用所需模式，并在检查改变源码时断言「已过期」。只读探路动作实际在规划角色中运行，笔记用例核对宿主支持的角色，同时保留独立 `scout` 身份被拒绝的用例。[工程检查](../tools/test_agent_code.py) · [角色调用](../loop/scoped_roles.py)
