# 任务核心使用用户选择的专项模型

子 Agent 沿用父核心的主模型配置，代劳父核心能做的工作。任务核心拓展父核心的能力，由用户选择另一模型处理额外的专项重活。两者复用 [原生 L0 的委派与成果契约](0003-native-l0-workers-and-public-plugin-contract.md)，父核心负责验收和交付。

任务核心贡献声明所需的模型角色。宿主在派发时绑定该角色的实际端点与模型，只在该绑定仍有效时执行。已有未声明模型角色的贡献按原有主模型作为子 Agent 运行。视觉核心是首个内置任务核心预设，复用此前的精确读图连接设置，支持用户切换已连接的供应商与模型。公开协议标识与历史回执继续兼容。
