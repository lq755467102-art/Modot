# 大核共用原生 L0，官方样例只使用公开插件契约

大核采用与主执行者相同的原生 L0 运行基底，分别持有历史、状态、任务要求和授权。规划者与探路者作为两个官方参考插件，使用与第三方相同的公开注册、委派、上下文和成果接口，不恢复角色名驱动的专用流水线，也不在插件内复制 loop。这样保留默认 L0 的独立性，并让官方样例实际检验扩展边界。

委派归属逻辑任务，一次父运行结束不再天然等于取消所有子任务；具体存续、停止、恢复和回收行为由宿主的公开契约定义。模型决定如何采用成果，底座负责真实状态、授权、版本、持久化及投递，不把运行结束当作成果验收。

工作间、记忆与大核贡献区分可复用逻辑和宿主适配。先在 Modot 内完成实现、健壮性与稳定性验证，再优先适配 DSH，其后 Codex；不同时兼容三家，也不承诺 MCP 或相似的插件清单等于整包可移植。复用现有安装、注册、存储和工具体系，新增的是公开能力契约，而非另一套插件生态。
