# 公开网页工具样包

需要查公开资料时，可从 Modot 插件页预览本目录，核对域名并安装，再启用 MCP。服务名是 `web`。这项配置只作用于启用它的用户，新授权会在下一轮会话生效。

在会话里可以要求“查找 Python 官方 pathlib 文档，并从该页核对一个示例”。L0 可以通过插件组发现服务，读取实时工具声明，选择检索或按 URL 阅读。搜索提供的片段和实际读到的正文在回执里可以区分。关闭 MCP 即可撤回使用权。

服务商会收到调用参数中的查询词或 URL。本样包不含密钥、脚本或安装钩子。网络可用性、调用额度，以及服务发布的工具声明决定实际可用范围。目录返回的权限标注不能满足 Modot 的只读条件时，工具会保留其现行权限要求。 [Exa 服务说明](https://exa.ai/docs/get-started/exa-mcp)
