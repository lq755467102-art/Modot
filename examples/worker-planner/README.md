# 规划者

当执行者想比较两条路线或梳理下一步依赖时，可以把已知事实交给规划者。任务开始和途中都可调用。每次调用使用独立的原生 L0 历史。

在 Modot 的插件页选择本目录，预览后安装，在详情里启用“子 Agent 贡献”。下一轮从 `plugins` 工具组调用 `inspect_worker_plugins`，使用返回的 `worker` 标识。安装和启用独立于探路者。

[示例](example.json) 包含一对有效的 `input` 和 `output`。[声明](plugin.json) 包含完整的方法与字段约束。父方以 `kind: "report"` 委派，能用现成事实回答时传 `resource_ids: []`，需要读文件时只传对应资源。规划者通过 `submit_worker_result` 返回选项、依据和未解问题。资料不足时可返回空 `options` 并列出缺口。主任务队列、采用与验收都由执行者掌握。

开发自己的版本时，复制本目录、替换包名和贡献名、按任务修改方法与两个 Schema，并同步更新示例。预览和安装新指纹，先在一项固定任务上确认结果能读回，再测试停用后贡献从目录消失。完整的委派、续接、取消、处置及错误示例见[开发与验证指南](../../docs/protocols.md)。
